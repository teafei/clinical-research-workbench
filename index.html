WORKFLOW

从已有表格继续整理

面向脊柱外科回顾性研究资料，接收标准三表CSV、Excel或已有中文采集整理工作簿。患者、住院和检验分层处理。

  1. 导入与标准化：受控日期解析、单位换算、来源指纹。
  2. 质量检查：主外键、重复、缺失、时间顺序和冲突测量。
  3. 队列与描述：年龄、诊断、手术、日期过滤；明确检验时间窗和统计粒度。
  4. 审计导出：队列、质量问题、筛选流程与参数一起导出。

RUN LOCALLY

本地运行

需要Python 3.12。下载仓库后，建立虚拟环境并激活，再执行：

python -m pip install -r requirements.txt
python -m streamlit run app.py

在浏览器打开 http://127.0.0.1:8501，首次启动会加载合成数据。
