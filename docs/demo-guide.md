# 演示步骤（约3—5分钟）

1. 打开应用：说明当前是完全合成数据，80名虚构患者有101行住院记录，重复住院和重复导出分别处理。
2. 打开“数据质控”：按`DUPLICATE_KEY`查看重复主键如何整组排除，再查看`MEASUREMENT_CONFLICT`与`CENSORED_VALUE`。说明质量条目数与患者数不同。
3. 打开“队列与统计”：选择`PKP`并更新；观察每一步排除数。取消“每名患者保留最早一次”可比较住院和患者两个口径；修改CRP窗口可比较可用值与缺失分母。无符合数据时应显示空结果。
4. 打开“病历结构化”：选择病例A并生成候选。说明候选是预先编写的演示，突出“计划未实施”与“血培养未送检”不能写成已实施/阴性。填写审核者，对某字段通过或驳回；下载只含通过字段的结果及审核历史。
5. 打开“导出与审计”：检查筛选条件、来源SHA-256及CRP规则，再下载ZIP。打开其中Excel、质量问题CSV及audit.json核对口径。

如果需要演示导入，使用`sample_data`下三份CSV或页面下载的合成模板。公开展示过程中始终使用合成资料。

## 可以清楚说明的设计

- 医学背景用于发现数据口径和语义问题；产品流程将规则转为可操作步骤。
- AI辅助实现代码；规则、限制和结果需要显式验证。
- 候选抽取与人工审核分开；原文证据存在不代表语义一定正确。
- 当前成果是可运行的原型与测试，无真实效率提升或模型准确率数字。
