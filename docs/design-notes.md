# 工具设计记录

## 使用场景

准备脊柱外科回顾性研究数据时，先用已有采集和转换程序整理资料，再导入本工具核对住院关联、重复、日期、检验单位与缺失。按当前研究问题筛选候选队列，导出结果和检查记录供后续分析。

## 数据规则

- 同一患者可能多次住院，不能把住院行数当患者数。
- 检验必须同时看项目、标本、单位和时间，常规CRP与超敏CRP分别保存。
- 只有日期时不补出准确时刻，不参加小时级基线CRP选择。
- “未查、未记载、未知”不转成阴性；计划操作不等于已经实施。
- 冲突先列出，不为了方便而随意选择一个值。
- 候选字段先对照原文，再逐项确认；模型输出不直接写回研究表。

## 当前范围

已有中文工作簿适配、质控、队列筛选、描述统计和审计导出可运行。文本审核可用合成候选演示，可选本机模型接口仅完成模拟服务测试。合成数据有固定种子，方便改代码后检查同一套规则。

工具在本地运行，当前不包含账号和多人协作。源文件不改写，问题在原始资料中核实后重导入。尚未测量节省时间或真实模型准确率。
